# 無邊際白板 Infinite Whiteboard

![無邊際白板 Infinite Whiteboard UI](UI.png)

Infinite Whiteboard 是一款專為教學情境設計的無邊際虛擬白板，可直接在電腦、平板、手機或教室電子白板上使用，支援自由書寫、繪圖、加入便條貼，適合用於課程講解、概念整理、腦力激盪、小組討論與重點統整。使用者無須註冊帳號，也不必安裝額外軟體；有網路時可直接開啟網站使用，無網路時只需下載 `index.html` 並以瀏覽器開啟即可執行。白板內容不會上傳至伺服器，也不會留存任何使用資料，所有內容僅存在於目前使用的裝置與瀏覽器中；如需保存，可下載為圖片或匯出白板檔案，並於其他裝置重新匯入後繼續編輯。

直接使用：https://yu0604-coder.github.io/infinite-whiteboard-upgrade.v.r-/?utm_source=chatgpt.com

## 功能

- 自由筆刷、橡皮擦、直線、長方形、圓形、橢圓形；自由筆跡可用輪廓差集局部擦除，擦除處不會再被「選擇筆畫」選中
- 加入 200×200 便條貼，可選淡黃色、淡綠色、粉紅色、粉藍色並拖曳右下角調整大小
- 從裝置匯入 PNG、JPEG、WebP 或 GIF 圖片，圖片加入白板中心後可選取、移動、刪除及復原
- 筆畫橡皮擦，可一次刪除整個筆畫或圖形
- 筆畫選擇工具，可選取並移動單一筆畫、圖形或便條貼
- 便條貼內建刪除、編輯、確認編輯按鈕
- 刪除所選物件，支援按鈕與 `Delete` / `Backspace`
- 顏色選擇、快速色票與筆刷粗細調整
- 畫筆與橡皮擦分別記憶粗細，切換工具時自動恢復各自上次設定
- 滑桿旁顯示目前粗細數值，滑鼠在畫布上移動時顯示跟隨游標的尺寸預覽圓圈
- 筆跡平滑開關
- 返回上一步，支援按鈕與 `Ctrl/⌘+Z`
- 世界座標儲存筆跡，支援無邊際平移與縮放
- 滑鼠滾輪縮放、空白鍵拖曳平移、右鍵拖曳平移、平移工具單指拖曳
- 觸控單指繪圖、iPad/手機雙指平移與縮放
- iPad 書寫時停筆不觸發瀏覽器長按選單
- iPad/手機手寫效能優化，降低筆跡延遲與重繪負擔
- 自動儲存筆觸，重新整理後仍會保留白板內容
- 匯出目前畫面為 PNG
- 匯出 JSON、匯入 JSON 重建白板
- 匯入圖片檔案上限為 1 MB；加入白板的圖片會隨白板自動儲存，亦包含在 JSON 匯出檔中
- 無後端、無資料庫、無 npm build

## 使用方式

可直接開啟本網站使用，無須註冊帳號或安裝額外軟體。
支援電腦、平板、手機及教室電子白板。
本網站不會將白板內容上傳至伺服器，也不會留存任何使用資料。
白板內容僅存在於目前使用的裝置與瀏覽器中。
如需保存，可下載為圖片或匯出白板檔案，日後再匯入並繼續編輯。

電腦或平板有網路時，直接點連結使用。
無網路時，下載 `index.html` 用瀏覽器打開。

桌機操作：

- 滑鼠拖曳：使用目前工具繪圖
- 滾輪：以滑鼠位置為中心縮放
- 空白鍵 + 拖曳：平移白板
- 畫筆與橡皮擦可分別調整粗細；切換工具時會套用該工具上次設定的值
- 使用畫筆或橡皮擦時，將滑鼠移到畫布上即可查看實際大小的預覽圓圈；移出畫布後預覽會隱藏

觸控操作：

- 單指拖曳：使用目前工具繪圖
- 雙指拖曳：平移白板
- 雙指張合：縮放白板


匯入圖片：

- 點選工具列的「＋圖片」，再從裝置選取圖片；圖片會置於目前畫面中央。
- 圖片最長邊會縮放至 600 白板單位以內。匯入後可拖曳移動；要移除時先選取圖片，再按刪除按鈕或 `Delete` / `Backspace`。
- 圖片資料儲存在目前瀏覽器的本機白板資料中，不會上傳。匯入很多圖片可能佔用瀏覽器儲存空間；單張圖片限制為 1 MB。

橡皮擦操作：

- 選擇工具列的「橡皮擦」，沿著要移除的筆跡拖曳；筆刷粗細由「粗細」控制。
- 橡皮擦會將自由筆跡拆成剩餘的獨立區域；未被覆蓋的區域仍可分別選取及移動，擦除區域會跟著剩餘區域移動。直線、圖形與便條仍以附加擦除遮罩處理。
- 一次拖曳算一個動作，可使用「返回上一步」或 `Ctrl/⌘+Z` 還原。
- 「筆畫橡皮擦」仍可快速刪除整筆筆畫、圖形或便條。
- 一次橡皮擦拖曳可能同時附加到多筆相交筆跡；使用返回上一步會還原整次擦除。
- 載入舊版以獨立橡皮擦筆畫儲存的白板時，系統會在載入時轉成筆跡型擦除資料。

第三階段的橡皮擦會將自由筆跡展開成實際輪廓，再扣除橡皮擦輪廓；剩餘的連通區域會成為獨立物件。每個區域可以分別選取、移動及復原。直線、圖形與便條仍維持完整物件的擦除行為。

## 建議測試

1. 畫一條長筆跡，選「橡皮擦」擦過中段；確認中段消失、兩側仍在，且中段空白處無法選中原筆跡。
2. 用「選擇筆畫」點擊剩餘筆跡；確認仍可選取及移動，點擊擦除區域則不會選中原筆跡。
3. 擦除後按「返回上一步」或 `Ctrl/⌘+Z`；確認完整筆跡恢復，再重新擦除並重新整理，確認已擦除內容仍保持消失。
4. 擦過直線、圖形及便條；確認畫面上的覆蓋效果與選取判定一致，並可用返回上一步復原。
5. 用滑鼠與觸控各測試一遍，調整粗細與縮放比例後確認擦除範圍符合筆刷大小。
6. 匯出再匯入 JSON；確認擦除後留下的筆跡片段可正常顯示、選取與移動。
7. 移動曾經被局部擦除的筆跡，確認擦除區域會跟著筆跡移動，不會固定在原畫布位置。
8. 畫兩條交叉筆跡後擦過交叉區，確認同一次擦除會套用到兩筆筆跡，且返回上一步會同時還原。
9. 擦除自由筆跡後，確認切口依實際橡皮擦輪廓產生，不會因重新繪製而自動變成新的圓頭。
10. 用方框概念檢查分離後的筆跡區域是否能分別被選取；正式方框選取工具尚未加入。
11. 擦斷自由筆跡後，點擊切口空白處不應選中任一片段；點擊切口兩側則應能分別選取兩個區域。
12. 用粗筆刷畫出自交或重疊的繞圈筆跡，再擦除交疊區；確認重疊邊界不會形成大面積錯誤填色，剩餘區域仍可分別選取。

## 橡皮擦事件收尾修正

橡皮擦現在會在指標放開或取消時只提交一次，並清理離開畫布、失去指標捕獲及切換工具時的暫存狀態，避免白色預覽殘留或鎖住工具列。測試時請重整頁面後，依序驗證單次擦除、連續擦除、擦除後切換工具、畫布內外放開指標，以及復原功能。

複雜自由筆跡使用 `vendor/clipper.js` 將筆跡膨脹成區域後執行 Union 與 Difference；差集失敗時保留原筆跡，不使用錯誤的填色結果提交。
